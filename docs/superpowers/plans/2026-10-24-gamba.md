# Gamba Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `?gamba`, a three-reel weighted emoji slot machine that awards role `1561827731400822845` when all three reels are cpp.

**Architecture:** Game logic lives in plain modules under `src/features/gamba/` (no Discord imports, not a Sapphire store). `src/commands/misc/gamba.ts` is a thin Sapphire command that spins, assigns the role on a jackpot and replies. Randomness comes from `node:crypto`'s `randomInt`, injectable in pure functions and mocked with `vi.mock` in end-to-end tests.

**Tech Stack:** TypeScript (strict, NodeNext ESM), Sapphire 5 / discord.js 14, Vitest, Biome.

**Spec:** `docs/superpowers/specs/2026-10-24-gamba-design.md`

## Global Constraints

- Relative imports use `.js` extensions; type-only imports use `import type`.
- Log via `this.container.logger`, never `console`. Never log the token or environment.
- Mentions stay suppressed (client default); the command passes no `allowedMentions` override.
- No new env vars, intents or dependencies.
- Biome style: single quotes, 2-space indent, semicolons (run `pnpm lint:fix` if unsure).
- Every commit must pass `pnpm lint && pnpm typecheck && pnpm test && pnpm build`.
- Commit messages: Conventional Commits, ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Weights (exact): six yt emojis weight 3 each, python 2, cpp 1; total 21.
- Emoji strings (exact): `<:gamba4Head:1202741378161840239>`, `<:gambaCry:1083000042547322930>`, `<:gambaGrr:1098212404640358463>`, `<:gambaNails:1082999569291423815>`, `<:gambaRaa:1098212756810907729>`, `<:gambaSpooked:1083000047051997264>`, python `<:python:1226479453039759410>`, cpp `<:cpp:1226477956541448194>`.
- Reply copy (exact): `${user} GAMBA!\n${r1} ${r2} ${r3}`; jackpot adds `\nJACKPOT! You won <@&1561827731400822845>`; on role failure append ` (couldn't assign the role, tell a mod)` to that jackpot line.

## Review Focus

1. Jackpot where `message.member` is null (uncached member): must not throw; treat as role not assigned and send the failure note. Test in Task 4.
2. Jackpot where `roles.add` rejects (missing Manage Roles / hierarchy): reply still sent with the note, warning logged. Test in Task 4.
3. `?gamba` with trailing text (`?gamba lol`): still spins normally. Test in Task 3.
4. `?gamba` in a DM: no reply and no role call (GuildAny precondition). Test in Task 3.
5. Two cpp plus one other emoji: not a jackpot, no role call. Test in Task 4 (`isJackpot`).
